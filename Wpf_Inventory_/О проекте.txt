Описание структуры проекта
1. Общее описание
Проект представляет собой WPF-приложение для управления данными инвентаря. Основные функции включают работу с базой данных, кэширование данных, синхронизацию с сервером и отображение данных в интерфейсе. Приложение использует Entity Framework для взаимодействия с базой данных и JSON для кэширования.
---
2. Основные элементы проекта
2.1. Главное окно (MainWindow)
•	Файл: MainWindow.xaml и MainWindow.xaml.cs
•	Описание: Главное окно приложения с вкладками для работы с различными сущностями (устройства, офисы, типы, модели).
•	Функции:
•	Обновление индикатора статуса подключения.
•	Импорт/экспорт данных.
•	Пинг сервера и базы данных.
•	Сохранение данных.
•	Переключение между онлайн и оффлайн режимами.
•	Вызов окон для работы с устройствами, офисами и другими сущностями.
2.2. Контролы
•	DeviceControl: Управление устройствами.
•	OfficeControl: Управление офисами.
•	WorkspaceControl: Управление рабочими местами.
•	DeviceTypeControl: Управление типами устройств.
•	DeviceModelControl: Управление моделями устройств.
•	Функции контролов:
•	Инициализация таблиц данных.
•	Добавление, удаление и обновление записей.
•	Обработка событий (например, двойной клик по строке таблицы).
2.3. Класс LocalDataBase
•	Файл: LocalDataBase.cs
•	Описание: Управляет сохранением и загрузкой данных из кэша.
•	Функции:
•	Сохранение данных в формате JSON.
•	Загрузка данных из файла.
•	Получение базы данных из кэша.
2.4. Класс JsonCache
•	Файл: JsonCache.cs
•	Описание: Реализует кэширование данных в формате JSON.
•	Функции:
•	Сохранение объектов с использованием GUID.
•	Загрузка и сохранение данных в файл.
•	Извлечение данных по идентификатору.
2.5. Класс InventoryDataBaseContext
•	Файл: InventoryDataBaseContext.cs
•	Описание: Контекст базы данных, сгенерированный Entity Framework.
•	Сущности:
•	Device (Устройства)
•	Office (Офисы)
•	DeviceType (Типы устройств)
•	Model (Модели)
•	Другие таблицы, связанные с устройствами и рабочими местами.
---
3. Отношения между элементами
•	MainWindow:
•	Использует контролы (DeviceControl, OfficeControl и др.) для отображения данных.
•	Взаимодействует с LocalDataBase для сохранения и загрузки данных.
•	Обновляет статус подключения через DB_Connection.
•	Контролы:
•	Работают с InventoryDataBaseContext для выполнения операций с базой данных.
•	Используют методы для добавления, удаления и обновления данных.
•	LocalDataBase:
•	Использует JsonCache для кэширования данных.
•	Работает с InventoryDataBaseContext для сохранения данных в кэш.
•	JsonCache:
•	Сохраняет данные в формате JSON.
•	Обеспечивает сериализацию и десериализацию объектов.
